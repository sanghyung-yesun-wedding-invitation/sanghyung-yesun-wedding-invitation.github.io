# 정상형 · 최예선 모바일 청첩장

## 실행

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

공개 주소: https://sanghyung-yesun-wedding-invitation.github.io/
로컬: http://127.0.0.1:4173/
10번 화이트 디자인 하나만 사용하며 시안 선택 화면은 제거했습니다.

## 구성

바른손 원본 메인 사진 → 인사말 → 달력 → 참석 여부 → 갤러리 → 오시는 길.
음악·영상·신랑신부 소개·숫자 카운트다운·하단 감사 영역은 없습니다.
화환 안내는 오시는 길 제목 아래에 두 줄로 표시합니다.

사진 원본 JPEG 3장은 수정하지 않았습니다. 모바일용 WebP 사본을 `assets/photo-13.webp`~`15.webp`로 만들었습니다.
메인은 `photo-00.webp`이며 갤러리에는 중복되지 않습니다. 나머지 15장은 세 장씩 다음 순서입니다.

- 흰 스튜디오: 01, 03, 15
- 화이트/그린: 02, 04, 05
- 베이지 정장: 10, 06, 13
- 어두운 스튜디오: 07, 08, 09
- 블랙/핑크 포인트: 11, 14, 12

## 참석 여부

구글폼 임베드 없이 직접 만든 선택 버튼과 입력창을 사용합니다. 미참석 시 인원/식사는 숨겨지고 각각 0명/불참으로 전송합니다. 필수 입력 검사, 중복 클릭 방지, 오프라인/네트워크 실패 안내를 제공합니다.
응답 저장소만 기존 Google Form을 유지합니다. 질문의 ID와 선택값은 `rsvp-config.js`에 있습니다. 질문을 변경하면 매핑도 변경해야 합니다.

관리: https://docs.google.com/forms/d/1BmQlSRvZA5YJfVQuW00SxnpEr6UAjKd-2C2jK0zUiSY/edit#responses

정적 사이트에서 Google Forms에 `no-cors` POST를 사용합니다. 브라우저는 응답 본문/상태를 읽을 수 없으므로 완료 화면은 ‘전송했습니다’로 표현하며 서버 저장 확인을 주장하지 않습니다. 운영 중 저장 성공을 건별로 확인하려면 별도 서버 또는 Apps Script API로 교체해야 합니다. 현재 필드로 참석·미참석 두 경우를 브라우저에서 실제 제출하고 관리자 화면에서 저장을 확인했으며 테스트 응답은 삭제했습니다.

## 지도와 길찾기

`assets/kakao-map.png`는 사용자의 바른손 청첩장에 표시된 카카오맵 약도입니다. 카카오 표기를 유지했으며 클릭하면 해당 예식장 카카오맵으로 연결됩니다. 확대/이동은 연결된 지도에서 가능합니다. 카카오 모바일 페이지를 직접 임베드하면 앱 홍보 팝업이 지도를 가려 이미지 약도를 사용했습니다.

네이버지도 검색, T-MAP 목적지 앱 링크, 카카오 길찾기 링크를 제공합니다. 카카오내비 표기 버튼은 바른손 참고 화면과 동일하게 카카오맵 길찾기로 연결됩니다. 카카오내비 앱 직접 실행은 별도 Kakao SDK 키/도메인 설정이 필요합니다. T-MAP 앱 실행은 모바일 실기기에서 추가 확인이 필요합니다.

## 공유

맨 아래 공유 버튼은 메인 사진과 예식 정보를 보여주는 팝업을 엽니다. Web Share API 지원 브라우저에는 다른 앱으로 공유하기 버튼이 표시되고, 모든 브라우저에서 공개 URL 복사와 수동 복사를 지원합니다. 공유 취소는 오류로 표시하지 않습니다. 메신저 미리보기용 Open Graph 제목/설명/JPEG 이미지와 canonical URL을 설정했습니다. 실제 카드 모양은 메신저에 따라 다릅니다.

### 카카오톡 세로형 공유
- 카카오 앱 ID: 1641434 (`정상형 · 최예선 청첩장`). JavaScript SDK 도메인과 제품 링크 도메인은 현재 GitHub Pages 도메인으로 등록.
- `kakao-share.js`는 도메인 제한된 공개 JavaScript 키와 공식 SDK 2.8.4를 사용합니다. 어드민 키나 REST API 시크릿은 사용하지 않습니다.
- ‘카카오톡으로 공유하기’는 `Kakao.Share.sendDefault`에 1200×1600 세로형 카드와 청첩장 링크를 전달합니다. 전송 대상은 사용자가 카카오 화면에서 선택합니다.
- `assets/kakao-share-portrait-filled.jpg`는 `tools/kakao-card.html`의 600×800 CSS 구성물을 DPR 2로 캡처한 이미지입니다. 원본 사진을 cover로 확대해 3:4 영역을 채우며, 좌우 여백 없이 위아래 일부를 자릅니다.
- 공유 창은 같은 세로형 이미지 전체를 표시합니다. URL 복사·붙여넣기는 별도의 OG 미리보기이며 세로형 SDK 카드와 다릅니다.
